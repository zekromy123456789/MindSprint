# Known issues and limitations

- Risk Classic intentionally preserves the reference source's green-to-red probability fall-through; it has not been independently confirmed statistically in live play. Hardware arrow routing is implemented but synthetic or physical arrow delivery, haptics, VoiceOver and real-device behavior are unverified.

- Memory uses one-second lead-in and one-second-per-digit card presentation, an independent pacing choice; exact source spring settling and real-time UI behavior on device remain unverified. Submission is gated until presentation completes, intentionally avoiding the source's suspected premature-submit issue. Background interruption restarts playback; actual device backgrounding, long sequences, VoiceOver and Dynamic Type need QA.

- Optiver gameplay and reference-style precision/offset ranges passed simulator CI. Fixed-point arithmetic, normalized negative zero, independent random sequence and zero/ambiguity resampling intentionally differ from source; exact binary rounding boundaries remain unverified. They intentionally avoid zero divisors and ambiguous zero-factor questions. Reference-style precision and offset ranges are implemented; exact binary rounding and random sequence equivalence are unverified.

- Sequence Classic and custom difficulties passed simulator tests. Sample Classic default light-mode screenshots were reviewed on both sizes; the new difficulty screen has not been visually reviewed. Longest sequences, larger text, dark mode, physical device, VoiceOver and actual background behavior remain unverified.

- Arithmetic Pro is playable in simulators with four custom difficulty levels; its independently authored five-template distribution does not reproduce the protected reference pool. UI tests use a frozen DEBUG-only clock. Pro and Arithmetic round and view implementations duplicate behavior.
- Arithmetic passed end-to-end simulator playthroughs in run 41170294927. A previous large-simulator replay attempt failed; after the replay transition changed, subsequent runs succeeded on the first tap, but the UI test permits one retry and intermittent behavior cannot be ruled out. Earlier active and result screenshots on both sizes showed no obvious clipping; the final-question addition has not been separately visually reviewed. Physical-device gameplay remains unverified. Sequence and its custom difficulty options passed simulator playthroughs; two other games are unavailable. Generator tests do not directly check statistical distribution.

- Run 41165821335 passed 16 unit tests and four UI tests on each of iPhone 17 Pro and Pro Max simulators. It verifies synthesized keyboard events and haptic preference persistence, not actual physical keyboard behavior or haptic feel. VoiceOver and real-device focus lifecycle are unverified. Six default light-mode screenshots showed no clipping, overlapping controls or software-keyboard intrusion; other modes, accessibility text sizes and actual game layouts need review.
- The unsigned arm64 app and IPA archive passed CI checks in run 41331629289 attempt 2. Installation and LiveContainer compatibility have not been verified on a device. Artifact 13094955630 expires 2027-01-30.
- Other games still need game-specific progression, duplicate-submission protection and background/expiry tests. Arithmetic has unit coverage for deadline and stale-question handling; actual background behavior remains unverified. Shared sessions require refresh when the app resumes. Numeric input's digit limit does not itself validate conversion overflow; game validators must do so. Haptic result feedback is not connected to games. Records and settings are incomplete.
- All eight games have initial evidence-labelled research. The supplied Optiver generator can select a zero divisor; avoid invalid questions and document the deviation. Optiver rounding and rapid-tap behavior require tests. Source inspection suggests Risk green balloons use red probability due to fall-through, Memory may allow premature submission, and Letter Speed may briefly show a stale timer; these were not independently reproduced. Full-session outcomes and correct Letter Speed time scoring remain incompletely observed. Pro selects from a protected fixed pool and has a potential out-of-range index; do not copy its pool or reproduce the crash. Exact independent Pro distribution remains unresolved.
- Local Git status and commit are blocked by a Windows ownership mismatch. The GitHub connector updates the remote; local and remote Git histories are not synchronized.
- Local Windows lacks Xcode and the iOS SDK. CI installs an unpinned XcodeGen version; runner or dependency changes can affect reproducibility.
